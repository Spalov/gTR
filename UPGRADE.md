# Обновление до gTR Beta 6

Распакуйте gTR-Beta-6-Windows-x64.zip в новую локальную папку. Сверьте хеш с SHA256SUMS и откройте gTR.cmd. Установленные версии живут рядом. Проекты, реестр, профили и сессия продолжают храниться в пользовательских данных Windows. [Данные и обратный переход](docs/DATABASE_MIGRATION.md)

Beta 5 (Fix) распознаёт ZIP Beta 6 по имени и устанавливает отдельно после проверки доступной официальной контрольной суммы. Для локальной сборки используйте ручную распаковку. Поддержка автоматической установки из каталога загрузок остаётся для официально опубликованной версии. При отказе Windows запустить C++ доступна команда gTR.cmd classic.

## Предыдущий переход на Beta 5 (Fix)

1. Скачайте gTR-Beta-5-Fix-Windows-x64.zip. Сверьте SHA-256 с gTR-Beta-5-Fix-SHA256SUMS.txt.
2. Распакуйте весь ZIP в отдельную папку и запустите gTR.exe или gTR.cmd из неё.
3. Откройте свой проект в разделе «Архив». Пакеты, профили и журналы Beta 5 остаются доступны через локальное хранилище.

Установленная Beta 5 ищет архивы со старым форматом имён, поэтому переход на Beta 5 (Fix) выполняется распаковкой и запуском. Beta 5 (Fix) понимает номер исправления и функцию установки следующих выпусков в отдельную папку. После согласия программа сверяет размер и SHA-256 с данными GitHub Releases и проверяет открытие нового окна. При сбое запуска остаётся доступна прежняя рабочая версия.
