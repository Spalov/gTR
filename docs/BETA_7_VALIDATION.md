# gTR Beta 7 — инженерный отчёт

**Локальная тестовая поставка · Windows x64 · 27 ноября 2026**

Резервная точка Beta 6 (Fix 2) сверена по SHA-256. Её ZIP и архив исходников сохранены. Beta 7 использует прежний каталог проектов и версионированный контракт пакета с дополнительным снимком выбранных записей.

## Реестр дефектов

| Приоритет | Сценарий | Причина и исправление | Проверка |
|---|---|---|---|
| P1 | Вход, импорт или история из C++ открывали второе окно | Оболочка вызывала прежний GUI. Обычные действия подключены к IPC 2 и собственным диалогам Qt. | CTest, тест потока владельца на имитаторе |
| P1 | Смена состава после подготовки оставляла готовый пакет | Пакет не хранил ревизию выборки. Снимок привязан к пресету, проекту и интервалам, сверяется перед отправкой. | `test_beta7_editor.py` |
| P1 | Повтор ошибки кода второго аккаунта закрывал шаг входа | Блок очистки завершал сеанс при любом исключении. Повторный код или пароль теперь остаётся в текущем шаге. | Регрессии авторизации и тестового режима |
| P1 | Неправильное переключение версии могло оставить рабочие файлы в частично обновлённом состоянии | Предыдущий ZIP устанавливался отдельно. GAU проверяет полную копию и использует журнал переключения с восстановлением. | Автономные испытания GAU со сбоем запуска и сымитированным обрывом |
| P1 | После отказа до запуска оператор получал общий код проверки | Движок теперь сохраняет указанный этап, компонент, причину и рекомендации. Проверка Beta 6 (Fix 2) продолжает разделять схему, привязку, хеши и хранение. | `test_package_validation_hotfix.py` |
| P1 | Скачивание в пустой профиль могло остановиться до проверки данных | Каталог загрузок создаётся до записи частичного файла и ETag. | Автономные тесты неправильного SHA-256 и первой загрузки |
| P1 | Запрос списка GitHub из нового клиента отклонялся TLS | Явно настроен TLS 1.2 с системной проверкой сертификатов. | Чтение общедоступного REST API без токена |
| P1 | Запрет запуска сборки Windows выглядел как повреждение комплекта | Явное состояние `APP_CONTROL`; GAU отменяет переключение и сохраняет прежний рабочий каталог. | Проверочный запуск локального GSU и журнал Code Integrity |
| P2 | Архив и история могли обрезаться при 200% | Фильтры вынесены отдельным рядом, действия истории сгруппированы в меню. | Набор оконных проверок при 100% и 200% |
| P2 | Неисправный рабочий профиль мог закрыть окно вместе с движком | Служба имеет проверку версии, тайм-аут бездействия и перезапуск по запросу. Диагностика доступна после сбоя. | IPC, восстановление после прерывания процесса |

## Готовность к публикации

Для публичного выпуска нужны настройка производственного ключа, идентификаторы реальных активов из GitHub draft, подписи и повторный контроль чистого комплекта. Затем следует контрольный импорт после согласия владельцев обоих тестовых аккаунтов. Ограничения текущей реализации перечислены в [KNOWN_LIMITATIONS.md](../KNOWN_LIMITATIONS.md).
