# Источник выпусков GitHub

Коннектор обращается к REST API публичного репозитория `Spalov/gTR` без авторизации. Список выпусков разбивается на страницы. Ответы кэшируются с ETag. При 403 и 429 повтор откладывается согласно заголовкам и локальному интервалу.

Тег и имя файла помогают сопоставить активы. Машинная версия берётся из проверенной подписи. Идентификаторы релиза и актива, имя, размер и SHA-256 сверяются с подписанными метаданными. Черновики пропускаются. Выпуски без доверенных метаданных недоступны для установки.

Скачивание ограничено HTTPS и известными узлами GitHub. Частичный ответ пригоден для продолжения только при том же сильном ETag и точном Content-Range. Полный файл проверяется по размеру и SHA-256.
