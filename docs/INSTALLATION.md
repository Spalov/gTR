# Установка в Windows

Откройте общий установщик `gTR-Beta-7-Setup-Windows-x64.exe`. Выберите папку для программных файлов и при желании ярлыки на рабочем столе. Установщик добавляет gAssets и проверяет вложенный GSU перед установкой gTR. Для установки отдельный архив gAssets не требуется.

Каталог `gTR/current` содержит активную программу и остаётся целью ярлыков после будущих обновлений. Проекты, реестр операций и данные DPAPI находятся отдельно. Удаление gTR через библиотеку или список установленных приложений сохраняет их.

У тестового комплекта отдельная запись «Test» и отдельный профиль gTR. Windows проверяет Authenticode независимо от внутренней подписи пакета GSU.

Нужны Windows x64 10 версии 1809 или новее и установленный .NET Framework 4.8 или новее. [Требования Qt](https://doc.qt.io/qt-6.12/windows.html) · [Требования .NET Framework](https://learn.microsoft.com/dotnet/framework/get-started/system-requirements)
