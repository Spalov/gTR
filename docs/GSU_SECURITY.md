# Доверие к GSU

Сверяйте источник начального gAssets Setup с каналом Gruzin. Встроенная точка доверия закрепляет открытый ключ. Манифест и каталог проверяются Windows CNG. Самоподписанный ключ из загруженного файла не меняет доверие.

Распаковка выполняется в новой папке одного продукта. GAU проверяет относительные имена, коллизии, ссылки и reparse points, количество записей, распакованный объём, подпись и SHA-256 каждого файла. Рабочая версия переключается после этих проверок. Путь проектов и сессий хранится отдельно.

Храните производственный ключ отдельно от проекта и публичного CI. Держите зашифрованную резервную копию с отдельным доступом. При потере или компрометации прекратите выпуск пакетов с прежним ключом и предоставьте через доверенный канал новый начальный установщик, после проверки владельцем. Автоматическая ротация ключей для GAU 1 отсутствует.
