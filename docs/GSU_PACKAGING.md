# Сборка GSU

Сначала соберите переносимый Windows ZIP командой из [руководства сборки](BUILD.md). Затем запустите `packaging/gassets_release.py` через среду разработки Windows. Нужны OpenSSL, Visual Studio Build Tools с C#, .NET Framework 4.8 SDK, PySide6 для значков и Inno Setup для установщика.

`--test --output <папка>` создаёт временный тестовый ключ и отдельный комплект. Для подписания выпуска передайте закрытый ключ через `--key-file <путь>` из доверенной среды разработчика. Подготовленная сборка использует закреплённый открытый ключ для сверки. В выходной комплект попадают только исполняемые файлы, публичная информация и подписи.

Для подписи исполняемых файлов Windows передайте `--sign-tool`, `--certificate-thumbprint` и `--timestamp-url` обоим сборщикам. gAssets проверит подписи обоих EXE внутри указанного Windows ZIP. Подпись установщика и программы удаления выполняется при сборке Inno Setup. [Порядок подписи](BUILD.md#authenticode)
