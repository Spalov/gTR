# Матрица Telegram History Import

gTR использует штатный импорт истории MTProto. Инициализация принимает текстовый файл и число вложений. Загрузка медиа принимает имя для сопоставления и InputMedia. Завершение возвращает ответ на запрос запуска. Результат сверяется последующим чтением истории и в клиентах. [History Import](https://core.telegram.org/api/import)

Во всех строках клиентский результат Beta 5 требует ручной проверки. Техническая возможность в таблице относится к формату запроса, подготовке gTR и локальной симуляции.

| Исходное свойство | Наличие в экспорте | Локально в gTR | Через History Import | Наблюдение в клиенте Beta 5 и ограничения |
|---|---|---|---|---|
| Текст, Unicode, эмодзи, переносы | JSON и HTML | Исходный текст и разметка | Обычный текст в файле истории | Непроверено. Возможна нормализация клиентом |
| Подпись и время | Если присутствуют | Историческая подпись, исходная и UTC-дата | Текстовый формат с подписью и временем | Непроверено. Серверный момент, отправитель и направление определяет Telegram |
| Время в одну секунду | Доступно | Порядок экспорта сохранён | Записи в исходном порядке с одинаковым временем | Непроверено. Формат пакета не передаёт отдельное смещение каждой записи |
| Фото и подпись | Если экспортированы | Оригинальные байты и связь | Фото и текст | Непроверено. Telegram может изменить байты фото |
| Видео | Если экспортировано | Оригинал, данные FFprobe и результат подготовки | Видеодокумент с проверенными атрибутами | Непроверено. Сверять ответ загрузки и два клиента |
| Круглое видео | Если отмечено | Тип и размеры | round_message на совместимом файле | Непроверено. Отдельно сверить круглое отображение |
| Голос и музыка | Если экспортированы | Байты, роли и теги | DocumentAttributeAudio, voice, название и исполнитель при наличии | Непроверено. Учет контейнера, длительности и кодека |
| GIF, анимация, стикер | Если экспортированы | Файлы и сведения | Атрибуты при подходящем формате | Непроверено. Анимация и тип стикера зависят от Telegram |
| Имя и байты документа | Если экспортированы | Исходное и безопасное имена, SHA-256 | Загрузка документа с именем | Непроверено. Возможна обработка имени или MIME сервером |
| Исходный ID и серверный отправитель | Иногда доступны | Отдельно от исторической подписи | Назначаются Telegram | Сопоставление после чтения через текст, время и контекст |
| Пересылка и скрытый профиль | Доступные исторические поля | Хранятся как сведения из архива | Можно добавить текстовую пометку | Нативный заголовок нельзя назначить через History Import |
| Ответы, цитаты, альбомы | Когда учтены экспортом | Связь по исходному ID или ключу альбома | Обычный текст и файлы, опционально текст цитаты | Нативные связи и группировка этим методом не задаются |
| Разметка, реакции, правки, закрепления, прочтение | Частично | Сохраняются доступные поля | Формат History Import не документирует эти поля | Создание исторических состояний через API не предусмотрено |

Метод forwardMessages действует на живые сообщения доступного диалога и не воспроизводит произвольный оригинал из локального экспорта.
