# Редактор архива

Откройте экспорт Telegram Desktop или готовый проект. В разделе «Архив» выберите диалог. Через «Фильтры» можно искать по тексту, автору, исходному ID, имени вложения, периоду и виду записи. Чтобы перейти к дате, укажите её в обеих границах фильтра.

Выделите записи через Ctrl или Shift и выберите действие в меню «Редактор архива». Диапазон задаётся номерами записей, которые показаны в карточке сообщения. Действие для всех совпадений захватывает все страницы текущего фильтра. Кнопки со стрелками восстанавливают предыдущий или следующий состав. «Вернуть исходный состав» включает все архивные записи в текущую выборку.

Сохраните отдельную выборку под именем, чтобы переключаться между несколькими составами. Локальные отметки доступны в карточке записи. Сводка будущего импорта показывает вложения, исторические даты, разрывы, разделённые альбомы и отсутствующих адресатов ответов. Точный объём отправки и ограничения совместимости появляются после анализа в разделе «Восстановление».

Для общего диалога согласуйте с участниками состав будущего импорта. Если выбрана часть истории, gTR укажет это на этапе анализа и в подтверждении согласия.
