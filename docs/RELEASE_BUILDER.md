# Подготовка выпуска gAssets

Проверьте код, тесты, аудит выходных файлов и SHA-256. Соберите GSU из готового Windows x64 ZIP. После разрешения автора загрузите файлы в GitHub draft и получите фактические ID релиза и GSU.

Запустите `packaging/gassets_release.py` с `--package`, `--release-ids <релиз> <актив>`, `--tag`, `--published-at`, `--sequence`, `--key-file` и `--output`. Дата поставки должна включать часовой пояс. Загрузите готовые метаданные и подпись после проверки. Для публикации требуется отдельное согласие автора. После неё повторите проверку обычным клиентом без GitHub Token.
