# Пересланные сообщения

Автор сообщения в диалоге и первоначальный автор пересылки представлены раздельно. Модель сохраняет доступные историческое имя, тип источника, исходные дату и ID, источник сведений, степень уверенности и состояние приватности. Пропущенные поля имеют состояние «неизвестно». Историческая подпись сама по себе не связывается с Telegram ID.

В разделе «Пересланные сообщения» видны подпись из экспорта и состояние профиля. Скрытие обозначается при явном признаке приватности. Кнопка «Обновить имена на этой странице» обращается к Telegram с подключённого аккаунта и использует только явные пользовательские ID из архива. При совпадении проверенного ID приоритет у имени из контактов, затем у доступного публичного имени. При недоступности профиля остаётся историческая подпись. Текущие имена хранятся в памяти просмотра, отдельно от проекта и пакета.

JSON предпочтителен при одновременной доступности форматов. Сопоставление с HTML требует уникального диалога по заголовку и совпадения исходного ID и текста. При конфликте сохраняются независимые свидетельства. Скрытый профиль исключается из поиска, даже если исходный документ содержит противоречащий ему ID.

При явном выборе можно добавить в отправляемый текст историческую пометку или цитату. Предварительный план показывает число изменённых записей. Оригинальный текст и воссозданная подпись проверяются отдельно. Пометка использует историческую подпись и не включает ID или текущие локальные имена. Нативный заголовок пересылки управляется Telegram. [History Import](https://core.telegram.org/api/import) · [MessageFwdHeader](https://core.telegram.org/constructor/messageFwdHeader)
