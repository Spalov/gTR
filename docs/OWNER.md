# Руководство пользователя gTR

## Подключение Telegram

1. Войдите на [my.telegram.org](https://my.telegram.org/) под своим номером и откройте **API development tools**. Создайте приложение или откройте уже зарегистрированное под этим номером.
2. В gTR откройте «Telegram». Введите выданные этому приложению **API ID** и **API hash**, отметьте «Запомнить API ID и API hash в Windows» и укажите номер аккаунта для входа.
3. Нажмите «Подключить Telegram…». Введите код, который выдаст Telegram, и пароль двухэтапной проверки, если он потребуется.
4. При следующем запуске gTR предложит сохранённые данные API. Сохранение авторизованной сессии включается отдельным флажком. Windows защищает эти две записи раздельно под вашей учётной записью.

Данные API можно удалить кнопкой «Удалить данные API…». [Справка Telegram о регистрации приложения](https://core.telegram.org/api/obtaining_api_id)

В карточке появляются аватар, имя, ID, имя пользователя, Premium, статус активности и приблизительный возраст, если Telegram сообщил месяц регистрации. Последняя активность показывается с точностью, доступной Telegram. Обновить сведения можно кнопкой «Обновить карточку».

## Продолжение импорта

1. Откройте «Профили импорта». При первом использовании выберите в разделе Telegram свой аккаунт и целевой диалог. Следующие архивы можно проверять в сохранённом профиле без подключения.
2. Выберите профиль и откройте обновлённый экспорт или сохранённый проект. Проверьте числовые ID аккаунта и диалога. Через «Изменить параметры» доступны исходный диалог, диапазон записей и режим вложений.
3. Сверьте общее количество, подтверждённые, доступные и требующие проверки записи. Кнопка «Проверить совпадения» показывает решение для каждого исходного номера.
4. Нажмите «Продолжить импорт». Приложение сохранит подготавливаемые записи в отдельный пакет. Его можно оставить до следующего запуска. Для отправки подключите аккаунт профиля, выберите тот же диалог, подтвердите согласие участников и прочитайте подтверждение Telegram. Финальная кнопка «Начать импорт» запускает отправку.
5. В «Истории импортов» выберите операцию по дате, аккаунту и диалогу. «Проверить результат» открывает её сохранённый пакет. Доступны список записей, отчёт и обезличенная диагностика.

Флажок «Проверять предыдущие операции» находится в разделе «Изменить параметры». Он включён по умолчанию и сохраняется отдельно для каждого профиля. Снимите его, если хотите продолжить импорт однозначно новых записей при неизвестном результате прежнего запуска. Приложение исключает совпадения и записи с неизвестным исходом. Если состав прежней операции установить невозможно, сначала уточните его. Активные импорты и интервалы ожидания Telegram учитываются при запуске.

## Повторный импорт после очистки тестового диалога

1. Очистите личный диалог у обоих тестовых аккаунтов в Telegram. В gTR подключите первый аккаунт и откройте профиль этого диалога.
2. В разделе «Изменить параметры» включите «Режим тестирования», затем нажмите «Сбросить реестр тестовых импортов». Проверьте два ID и подтвердите, что аккаунты принадлежат вам.
3. Введите номер второго аккаунта, код входа и пароль двухэтапной проверки, если Telegram его запросит. gTR проверит обе истории по отдельности и закроет подключение второго аккаунта по завершении проверки.
4. После сообщения о новом цикле нажмите «Продолжить импорт». Выборка охватит весь открытый архив в выбранном режиме вложений. Проверьте подготовленный пакет и подтвердите отправку в диалог.

Если сообщения ещё видны хотя бы с одной стороны, очистите соответствующую историю в Telegram и повторите проверку. Все принятые операции и диагностические отчёты можно открыть в «Истории импортов». После перезапуска включите тестовый режим в этом профиле и заново подготовьте пакет для последнего подтверждённого цикла.

## Ручная приёмка на двух собственных аккаунтах

Для этого испытания нужны два отдельно авторизованных аккаунта владельца и выделенный тестовый диалог. Создайте три вложенных по составу синтетических экспорта локальной командой из распакованного комплекта. Укажите новую пустую по назначению папку.

~~~powershell
.\gTR.cmd fixture-series --out "$env:TEMP\gTR-серия-проверки"
~~~

| Экспорт | Новые записи | Вложений в новой партии |
|---|---:|---:|
| Экспорт-10 | 10 | 0 |
| Экспорт-30 | 20 | 0 |
| Экспорт-120 | 90 | 83 |

В каждом экспорте откройте папку с result.json. Используйте один профиль, исходные даты и полный режим медиа. Убедитесь, что состав очередной партии совпал с таблицей. У предыдущих партий могут оставаться записи со статусом «Требуется сверка». Они тоже исключаются из новой партии.

Перед каждой отправкой сохраните границу для конкретного пакета отдельно с каждого аккаунта. Перепроверьте числовые ID, даты и авторские подписи. Передача в Telegram требует отдельного решения владельца для каждой партии. Запишите количество принятых файлов и ответ на запуск.

После каждой партии снимите независимую историю с обоих аккаунтов. Проверьте диапазон исходных исторических дат, повторы и порядок записей в одной секунде. Сопоставьте подпись и текст отдельно от серверного отправителя. Для медиа сравните имя документа, откройте изображение, проверьте читаемость файла и отметьте замену имени клиентом, если она произошла. Полностью перезапустите оба клиента и повторите проверку. Сохраните обезличенные результаты. Если запрос запуска остался без ответа, сохраните это состояние и перейдите к сверке.

Для проверки восстановления закройте gTR, уберите из тестового расположения только первоначальный пакет, оставив каталог данных приложения на месте. После перезапуска откройте операцию из истории. Ручное испытание использует синтетические данные и запускается отдельно владельцем.

## Открытие истории

1. Распакуйте весь комплект, запустите **gTR.exe** или **gTR.cmd**. Откройте **Импорт → Мастер импорта**.
2. Выберите экспорт Telegram Desktop, папку экспорта, существующий проект либо готовый пакет. Для HTML сохраняйте все страницы и папки файлов вместе. Если в старом проекте у дат с GMT много ошибок, создайте новый проект из того же экспорта.
3. Проверьте историю. В **Верификации** можно открыть отчёт с датами, которые gTR прочитал из `title`, `datetime` или других полей HTML. Для даты без смещения используется указанный часовой пояс. Конфликтующие даты и неоднозначные часы указаны в отчёте.
4. Чтобы продолжить без аккаунта, отметьте локальную подготовку. Выберите режим и диапазон исходных номеров записей. Верхняя граница включается. Откройте отчёт пакета, чтобы увидеть служебные записи, исключённые файлы и ограничения.
5. На шаге вложений проверьте результаты. Когда медиа не подходит для выбранного способа отправки, вернитесь в режим и явно выберите передачу документом либо текстовый пакет. Хеши, типы, размеры и исходные пути доступны в локальном отчёте. gTR оставляет обнаруженные одинаковые вложения в их исходных позициях.

В **Переписке** доступен просмотр изображений и WAV. Для кадров видео можно указать установленный локальный FFmpeg в **Настройках**. Вложения открываются из проверенной копии. Исходный экспорт и резервные копии храните на локальном диске отдельно от пакетов.

## Проверка владельцем на двух тестовых аккаунтах

1. Создайте отдельный личный чат между двумя своими тестовыми аккаунтами. В мастере выберите **Синтетические данные**, затем **Только синтетический текст** и размер **2**. Сохраните пакет в новую папку.
2. Подключите каждый аккаунт по очереди во вкладке **Telegram** и загрузите его диалоги. Для первого выберите чат со вторым, для второго — обратный чат. На шаге подтверждения сохраните исходную границу отдельно под каждым аккаунтом. Два файла границы относятся к одному пакету и разным аккаунтам.
3. Вернитесь к первому аккаунту и проверьте цель. Явно подтвердите согласие всех затрагиваемых участников. Нажмите **Проверить пакет в Telegram**. Проверка передаёт до 100 первых строк. Сверьте имя аккаунта, цель, объём и текст Telegram в отдельном окне запуска.
4. При согласии выберите **Начать импорт**. Зафиксируйте номер операции и ответ. Принятие запуска переводит операцию в ожидание сверки. При неопределённом ответе сохраните снимки и придерживайтесь [инструкции восстановления](SAFE_IMPORT.md).
5. Сохраните снимки истории отдельно под двумя аккаунтами. Для каждого выберите его файл границы. Когда поиск по ID не дал наблюдений, можно выбрать ограниченный интервал исторических дат UTC. Пустая или усечённая выборка оставляет результат неопределённым.
6. Откройте чат в официальных клиентах под обоими аккаунтами. Перезапустите клиенты и снова проверьте дату, метку импорта, историческую подпись, сторону, порядок и открытие вложений. В частном файле снимка заполните `client` и `after_restart`. Для наблюдавшихся строк доступны поля `visual_visible`, `visual_out`, `visual_name`, `visual_date`, `visual_precision`, `visual_rank`, `visual_jump` и `visual_media`. Запишите даты в ISO 8601 со смещением. Если видны только минуты, ставьте секунды `00` и точность `minute`. При видимых секундах используйте `second`. Неизвестные значения оставьте пустыми.
7. В мастере выберите **Сравнить сохранённые снимки…**. Для проверки стороны сопоставьте исторические подписи с двумя тестовыми аккаунтами. Сохраните обезличенный отчёт. Чтобы повторить наблюдение после перезапуска gTR, откройте тот же пакет, затем сохранённые файлы снимков.
8. После проверки текста отдельно подготовьте **Текст и синтетическое изображение**. Зафиксируйте принятие конкретного вложения и открытие медиа в обоих клиентах. В расширенном снимке можно явно запросить первые 4 КиБ файла или установить отдельный лимит полной сверки SHA-256. Разный хеш возможен после обработки медиа Telegram.

## Как читать итог

| Состояние | Значение |
|---|---|
| Подтверждено | Локальные данные, историческое содержимое и наблюдения в двух клиентах совпали. |
| Подтверждено частично | Часть полей подтверждена с двух сторон, для полной сверки не хватает данных. |
| Не подтверждено | Найдены расхождения. |
| Недостаточно данных | Подтверждающих наблюдений недостаточно. |

Историческая подпись показывает метку из источника. Серверный отправитель, аккаунт импорта и видимая сторона показаны отдельно. Восстановление исходных серверных ID и нативного авторства API не поддерживает. [Описание History Import](https://core.telegram.org/api/import)
