# Каталог приложений

Начальный продукт `gassets.gtr` закреплён в поставке и связан с `Spalov/gTR`. Дополнительный каталог хранится как `gassets-catalog.json` и `gassets-catalog.sig`. Схема 1 задаёт порядковый номер, срок действия и описания продуктов с архитектурой, форматом, допустимыми каналами, репозиторием, относительным каталогом программы, EXE и ID ключа.

Клиент проверяет подпись исходных байтов, срок действия и монотонность. Каталог может добавлять поддерживаемые продукты с уникальными каталогами. Для gTR действует закреплённый источник. Если дополнительный каталог недоступен, встроенное описание позволяет открыть локальную установку gTR. gFL остаётся самостоятельным продуктом.
