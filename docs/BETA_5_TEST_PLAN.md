# Ручная проверка Beta 5 в Telegram

Выполняет владелец на двух собственных тестовых аккаунтах, после согласия обоих участников тестового диалога. Используйте синтетическую переписку и небольшой экспорт. Сначала сохраните границу истории на обоих аккаунтах. Запишите версию gTR, версию Telegram Desktop и Telegram для iOS, SHA-256 пакета и выбранный режим медиа. Для каждого сценария сохраните отдельные сведения о локальной подготовке, ответе загрузки и отображении после перезапуска обоих клиентов.

| Сценарий | Ожидание | Результат в Telegram |
|---|---|---|
| Разные авторы, Unicode и переносы | Текст, подписи, последовательность и даты соответствуют источнику | Не проверен |
| Два сообщения с одним временем и переход +02:00/+03:00 | Пакет сохраняет секунды и порядок. Сверить исторический и серверный моменты | Не проверен |
| Исходный AVC/AAC MP4 и совместимая копия | В журнале видны параметры и вид ответа. На Desktop и iOS открываются как видео | Не проверен |
| Видео, исходно сохранённое документом | Сохраняет роль документа и доступное имя | Не проверен |
| Фото, голос, файл и круглое видео | Открываемый оригинальный тип, доступность вложения и подписи | Не проверен |
| Пересылки с исторической подписью и скрытым профилем | Модель остаётся доступной локально, пометка появляется только при включённой опции | Не проверен |
| Повторное открытие приложения без подтверждения запуска | Журнал остаётся пригодным для восстановления. История диалога без новой операции запуска | Не проверен |
| Импорт, удаление истории обоих участников, подтверждённый тестовый сброс, повторный импорт | После проверки пустой истории разрешён повторный архив. Старые журналы сохраняются | Не проверен |

Сохраните снимки с обоих подключений и явно дополните наблюдениями из клиентов. Если потерян ответ на запрос запуска, вернитесь к истории операции и снимкам. При серверном ожидании используйте указанный Telegram срок.
