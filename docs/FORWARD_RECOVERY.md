# Исторические пересылки

Открытый экспорт определяет автора записи и сведения о пересылке раздельно. Подтверждённый Telegram ID может использоваться при отдельном запросе имён аккаунтов через прежний интерфейс. При наличии достоверного совпадения предпочтение отдаётся имени контакта, затем доступному имени Telegram и исторической подписи. Совпадение имён само по себе не определяет личность. Скрытый Telegram ID не восстанавливается.

Режим «Только в архиве» сохраняет доступные сведения в каталоге. Краткая и подробная пометки добавляют историческую подпись отдельной строкой. Пометки доступны по-русски и по-украински. Локальные имена контактов, текущие профили и ID не входят в пометку.

Снимок различает импортный заголовок, обычный заголовок пересылки и отсутствие заголовка. Поля `from_id`, `from_name` и `date` сохраняются как отдельные свидетельства. History Import не принимает независимый заголовок каждой оригинальной пересылки. Для будущего прогона сравниваются два аккаунта, версии клиентов и результат API.
