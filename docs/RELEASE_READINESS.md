# Готовность Beta 7

Перед любым публичным выпуском требуется производственный ключ Gruzin, подписанные GSU и метаданные с фактическими идентификаторами GitHub, подтверждение автора и аудит финальных байтов. Отдельно проверьте установщик и входное окно на Windows с обычной пользовательской политикой запуска.

Контрольный запуск в настоящем тестовом диалоге, сравнение двух участников и отображение на iOS проверяются после отдельного согласия. Результаты имитатора и локальной сборки описаны в [отчёте об испытаниях](../TEST_REPORT.md).
