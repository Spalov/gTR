# Проверка безопасности gTR

## Beta 5 (Fix)

- Изоляция исходников и комплектов. Сборка берёт документацию и файлы программы из явного списка. Тестовые данные создаются на машине без доступа к Telegram. Публичный архив включает только синтетические тесты.
- Хранилище Windows. API Hash и Telegram-сессия защищены DPAPI текущего пользователя. gTR выставляет ограниченный доступ к новым папкам. Исходники чатов и отчёты на диске доступны владельцу в читаемом виде.
- Сетевые обращения. Telegram подключается по действиям владельца. Имена пересылок читаются по отдельному действию и остаются в интерфейсе. Проверка скачанного обновления запрашивает сведения о релизе у GitHub. Автоматическая отправка архивов и скрытая телеметрия отсутствуют.
- Недоверенные файлы. Архивы проверяются на выход из каталога, коллизии Windows, размер и количество элементов, ссылки и недопустимые типы записей. HTML преобразуется в ограниченную локальную разметку. Просмотрщик отключает загрузку ресурсов и открытие произвольных ссылок.
- Анализ медиа. FFmpeg и FFprobe запускаются отдельными процессами без оболочки. Входные демультиплексоры выбираются по сигнатуре, список протоколов ограничен локальным файлом. Число процессов и время ограничены, Windows Job дополнительно ограничивает дочерние процессы и память. Оригинал и совместимая копия проходят отдельную проверку SHA-256.
- Обновление. Используются HTTPS, указанный репозиторий, точный тег, размер и SHA-256 GitHub Releases. Извлечение выполняется в новой папке только после проверки. Неподписанная сборка имеет SHA-256 без криптографического удостоверения автора. Сценарий подписи сборки описан в BUILD.
- Восстановление операций. Журнал фиксирует границу необратимого запуска заранее и блокирует дубли при неизвестном ответе. При расхождении видео с ответом загрузки операция останавливается перед запуском.

Внешнее приложение для проигрывания медиа открывается по отдельному действию пользователя. Для FFmpeg и системных проигрывателей применяются обновления их поставщиков. [Отчёт тестов](../TEST_REPORT.md) · [Конфиденциальность](../PRIVACY.md) · [Процесс сообщения об уязвимости](../SECURITY.md)

## Beta 6

Локальный IPC использует наследуемые каналы, проверяет версию, типы, допустимые методы и предел кадра. Сессии DPAPI остаются у прежнего адаптера Telegram. Внешние медиапроцессы запускаются приостановленными и продолжаются после назначения Windows Job Object. Сеть ограничивается списком протоколов для локальных демультиплексоров. Job Object не изолирует доступ к файловой системе и сети на уровне всей ОС. Загрузка Qt привязана к комплекту и системным каталогам. Центральный каталог ZIP теперь проверяется до выделения объектов файлов. Локальные имена, ключи и сессии проверяются отдельно по окончательным ZIP.
