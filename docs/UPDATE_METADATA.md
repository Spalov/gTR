# Подписанное описание выпуска

`gassets-release.json` кодируется в UTF-8. Отдельный `gassets-release.sig` содержит 64 байта ECDSA P-256 (r‖s, IEEE P1363) с SHA-256 от точных байтов JSON.

Метаданные содержат версию схемы, продукт и репозиторий, канал, номер, исправление и Build ID, платформу, архитектуру, дату публикации и срок действия. Для доставки через GitHub обязательны реальные ID релиза и актива, тег, размер, SHA-256, минимальная версия GAU и минимальная сборка Windows. Числовой порядковый номер и хеш последних принятых байтов защищают от повтора или подмены уже принятого описания. Изменения передаются локализованными строками и показываются как обычный текст.

Локальный тестовый манифест использует `delivery: "local"`. У него нет идентификаторов GitHub. Такой манифест предназначен для проверок на диске.
