# Движок восстановления gTR Beta 5

| Этап | Результат | Проверка |
|---|---|---|
| Снимок ZIP, RAR, папки или отдельного файла | Собственная копия истории и вложений, размер и SHA-256 | Журнал обработки архива, сводка проекта |
| Разбор JSON или HTML | Исходные даты, смещения, текст, разметка и признаки служебных записей | Отчёт диагностики дат и ошибок проекта |
| Реконструкция | Каталог SQLite с исходным порядком, связями и свидетельствами пересылки | Разделы «Переписка» и «Пересланные сообщения» |
| Классификация | Тип по содержимому и исходному способу отправки, оригинальные и подготовленные медиа | «Проверить вложения…», локальный план, отчёт пакета |
| Подготовка | Текст History Import, файлы и манифест диапазона с хешами | Верификация A и локальная имитация |
| Импорт | Устойчивый журнал этапов, решения по совпавшим записям и ответам API | «История импортов» |
| Сверка | Свидетельства одного или двух аккаунтов и отдельных клиентов | «Верификация → Результаты восстановления» |

Каталог проекта хранит локальные связи с исходником. Пакет хранит только представления, используемые для импорта и проверки. Повторная подготовка использует каталог, а хеши подтверждают неизменность байтов. Исходные и преобразованные файлы находятся в разных папках.

Новые пакеты сохраняют экспортную последовательность и исторические даты. Одинаковое время в нескольких записях допустимо. При наличии полного смещения или Unix-времени сравнение ведётся по моменту UTC. Даты без смещения разбираются через выбранный пояс IANA. Повторённый или пропущенный час при сезонном переводе требует отдельной диагностики. При расхождении моментов JSON и HTML сохранены оба источника.

Для JSON отдельного диалога от 1 МиБ анализ идёт порциями. В первом проходе считываются заголовок и доступные подписи, во втором строки последовательно записываются в каталог. Для полной выгрузки аккаунта и сверки JSON с HTML сохраняется разбор целого дерева. HTML читается по страницам. Встроенный просмотрщик показывает по 40 записей, медиа загружаются по запросу. Манифест записывается построчно, а для проверки пакета загружается в память.

Архив, подготовленный пакет и их отчёты содержат персональную информацию. Обезличенные отчёты используют номера записей и технические категории. [Конфиденциальность](../PRIVACY.md)
