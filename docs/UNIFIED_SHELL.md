# Единая оболочка gTR

gTR запускает Qt Widgets на C++20, а затем фоновую службу Python. Пять разделов охватывают проект, редактор, подготовку, журнал и настройки. Вход в Telegram, карточка аккаунта, выбор диалога и подтверждение отправки используют диалоги Qt, принадлежащие тому же окну.

IPC 2 использует унаследованные каналы stdin/stdout, номера запросов, согласование версий и кадры до 1 МиБ. Запросы выполняются последовательно. Для Telegram используется долгоживущий цикл обработки событий. Подтверждение запуска связано с одноразовым идентификатором текущей проверки, аккаунтом, диалогом и манифестом.

Повторный запуск активирует имеющееся окно через канал Windows текущего пользователя. Именованный мьютекс также связывает штатный запуск с установщиком. `--diagnostic-profile <id>` открывает отдельное состояние, `--health-check` проверяет согласование оболочки с движком на временном пустом профиле.

После сбоя IPC перезапустите движок через окно gTR. Реестр операций хранит подтверждённый этап и исключает автоматическое повторение запуска с неизвестным ответом. Старые инструменты командной строки сохранены для разработки и чтения прежних данных.
