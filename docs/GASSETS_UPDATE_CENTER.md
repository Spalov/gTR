# gAssets Update Center

gAssets входит в общий установщик gTR. Из gTR он открывается через «Настройки → О программе → Проверить обновления в gAssets…».

В «Библиотеке» доступны запуск установленного продукта, папка программных файлов, восстановление, ручная установка GSU, откат и удаление программных файлов. «Обновления» показывают проверенную версию, дату, издателя, размер и подписанное описание. «Загрузки» показывают объём, скорость, остаток времени и позволяют остановить текущую загрузку. «История» хранит результаты установки и отката и сохраняет обезличенный JSON.

В «Настройках» можно выбрать канал, язык, интервал проверок и загрузку проверенных выпусков. Установка требует подтверждения. Ручной GSU можно открыть через диалог, перетащить в окно или выбрать gAssets через проводник Windows.

Комплект локального испытания использует отдельный путь установки, профиль запуска и записи Windows с пометкой Test.
