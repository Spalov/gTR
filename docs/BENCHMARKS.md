# Локальные измерения Beta 5 (Fix) и Beta 6

Один последовательный прогон на одной Windows x64 машине, CPython 3.14.6, одинаковые синтетические JSON с текстом и ответами. Условия включают кеш ОС и фоновую работу компьютера. Измерения относятся к Python-ядру. Старт — время импорта модулей. Поиск — проход по SQLite с одним результатом. Рабочий объём включает экспорт, проект и пакет после завершения. Пик памяти измерен для всего процесса.
