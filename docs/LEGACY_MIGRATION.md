# Переход с портативного gTR

Путь `%LOCALAPPDATA%\gAssets\gTR` используется для проектов, настроек, защищённых реквизитов и журналов. Перенос программы из прежней папки не требует переносить эти данные.

В gAssets выберите «Прежние установки» и укажите каталог одной из Beta 3–6. gAssets проверит наличие программы и сведения о выпуске. Затем установите доверенный GSU и откройте свои проекты. Прежде чем убрать старую папку, проверьте, что вы сохранили находящиеся в ней архивы, отчёты и другие пользовательские файлы. Старые папки остаются на месте, пока ими управляет пользователь.
