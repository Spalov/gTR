# Gruzin Software Update 1

GSU 1 — ZIP без многотомности, ZIP64 и комментария. Обязательные записи — `manifest.json`, `manifest.sig` и файлы из `payload/`, перечисленные в манифесте. Лицензии и справка размещаются вместе с устанавливаемыми файлами и подписываются их хешами.

Манифест включает продукт, машинную версию, ID пакета, платформу, архитектуру, путь запуска, минимальные версии GAU и Windows, версию совместимости пользовательских данных, требуемый объём, политику сохранения данных и список путей, размеров и SHA-256. Формат предполагает полный снимок программных файлов; `repair` допустим для той же доверенной версии. Дифференциальные комплекты отложены.

Внешняя подписанная запись дополнительно содержит хеш всего GSU. При ручном открытии можно проверить внутреннюю подпись без сети.
