# gAssets Universal Updater

GAU работает независимо от Python и установленного gTR. Код установки, HTTPS, подписи Windows CNG, регистрация приложений и пользовательский интерфейс используют .NET Framework 4.8. C++/Qt остаётся оболочкой gTR.

GAU получает описание продукта, сверяет подпись, архитектуру, версию, путь и свободное место. После распаковки в подготовительный каталог проверяется каждый файл. Переключение защищено мьютексом продукта и локальным журналом транзакции. Проверочный запуск открывает пустой профиль gTR.

Добавление подписанного описания допускается в рамках формата GSU 1, общей доверенной пары и поддерживаемых систем. Выпуск GAU и исходные проекты gTR имеют независимые версии.
