# Транзакционное обновление

GAU проверяет GSU и записывает журнал до подготовки. Новые файлы проверяются в `.stage`, пока текущая версия доступна в `current`. При переключении прежняя папка переходит в `.old`. Результат проверочного запуска фиксируется перед завершением записи реестра. После успешного обновления остаётся одна предыдущая рабочая копия `previous`.

Если процесс прервётся до подтверждённого запуска, следующий запуск GAU проверит журнал и вернёт прежний каталог. После подтверждённого запуска восстановление заканчивает регистрацию. Откат программных файлов запрашивается явно, сверяет подпись резервной копии и совместимость схемы данных. Исторически наибольшая доверенная версия сохраняется для проверки последующих установок.
