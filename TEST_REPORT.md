# Проверки gTR Beta 4

Автоматические проверки работают локально с вымышленными экспортами и ответами Telegram. Тесты блокируют сетевые соединения.

- Архивы HTML, JSON, ZIP и RAR, даты со смещением, порядок сообщений и проверка вложений.
- Контроль повтора по записям, восстановление операций и повторное тестирование после очистки обеих смоделированных историй.
- Отдельное хранилище API в Windows, загрузка сохранённых данных API, карточка аккаунта и отсутствие части полей в ответе Telegram.
- Поиск нового ZIP, сверка с данными официального выпуска, установка в отдельную папку и отказ при расхождении контрольной суммы.
- Первый запуск на отдельном профиле Windows с пустыми проектами, профилями и историей импортов. Открытие встроенной инструкции и загрузка синтетического экспорта.
- Содержимое Windows x64 ZIP и запуск комплекта с комплектным Python.

Команды повторения доступны в [инструкции сборки](docs/BUILD.md).
