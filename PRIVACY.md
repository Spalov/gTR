# Конфиденциальность

gTR хранит архивы, проекты, историю операций и настройки локально. Сохранённые API-данные и сессия защищены Windows DPAPI пользователя. Исходные файлы, пакеты, рабочие копии и частные отчёты могут содержать открытые персональные данные. Их местоположение показано в настройках.

При подключении программа общается напрямую с Telegram. История и вложения передаются выбранному диалогу только в ходе явного импорта. Список контактов читается только при запросе текущих имён открытых профилей пересылки. В архив и пакет эти локальные имена не попадают. Проверка обновления обращается к GitHub Releases и не передаёт туда содержимое проекта.

Публичный комплект не содержит переписок, пользовательских проектов, API-пары Gruzin, сессии или профилей автора. В исходниках тесты работают с вымышленными данными. Диагностические отчёты о медиа и сверке по умолчанию имеют обезличенный вариант. [Безопасность](SECURITY.md)
