# Безопасность gTR

Для сообщения об уязвимости используйте частный канал проекта при его доступности. Если создать частный отчёт нельзя, запросите способ связи в GitHub Issues и описывайте проблему без ключей, сессий, имён переписки, исходных архивов и персональных журналов.

Для воспроизведения используйте отдельный тестовый проект и обезличенный отчёт. Укажите Beta, формат экспорта, шаги, систему и техническое сообщение приложения. [Аудит](docs/SECURITY_AUDIT.md) · [Репозиторий](https://github.com/Spalov/gTR)
