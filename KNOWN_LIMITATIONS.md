# Ограничения gTR Beta 8

- Локальный GSU подписан тестовым ключом. Производственная точка доверия и Authenticode издателя ещё не настроены. Применяется обычная политика запуска Windows.
- Дифференциальные GSU и отдельный компонент для подписанного самообновления gAssets отложены. Проверка выпусков и загрузка полных пакетов для gTR реализованы.
- Центр обрабатывает одну загрузку одновременно. Открытие нескольких продуктов и расширенные сценарии поиска старых папок требуют дальнейшей проверки.
- Часть технических полей диагностики сохраняет язык движка или Telegram. Перевод отдельных текстов и окон ещё проверяется.
- Встроенное воспроизведение зависит от Windows Media Foundation. Рендеринг TGS, создание голосовой копии, GPU-кодирование и создание копий с контролируемой потерей прозрачности пока не добавлены. [Медиа](docs/MEDIA_ENGINE.md)
- Реальный импорт и сверка отображения Desktop и iOS требуют отдельного контрольного прогона. [План проверки](docs/BETA_7_TEST_PLAN.md)
- После обрыва перед финальным запросом gTR закрывает локальную подготовку отдельно от новой попытки. Официальный API не предоставляет способ проверить состав и безопасно возобновить частично загруженную подготовку.

- Нативные ID, направление сообщений, структура ответов, пересылок, альбомов, итоговый вид медиа и время создания назначаются Telegram. Архивные сведения остаются в проекте. [Матрица API](docs/API_LIMITATIONS.md)
- Расширенный анализ и преобразование видео используют локальные FFprobe и FFmpeg. При отсутствии доказательств совместимости пакет требует выбрать обработку. Для значительной части форматов поддержка проверена только локально.
- Формат файла History Import передаёт время без смещения каждой записи. gTR хранит оригинал и UTC отдельно. При конфликте дат или неоднозначном местном времени такие записи показываются отдельно.
- Потоковое чтение применяется к большим JSON отдельных диалогов. Выгрузка аккаунта, сравнение двух форматов и открытие большого манифеста требуют больше памяти. Нагрузочные замеры относятся к синтетическим данным.
- Мастер импорта и обработка медиа используют выбранный русский или украинский язык. Часть прежних экранов вне этого процесса и справки остаётся на русском.
- Подтверждение запуска означает принятие запроса. Независимая сверка требует снимков обоих аккаунтов и проверки в клиентах. [Матрица проверок](docs/CLIENT_COMPATIBILITY.md)
- Приложение запускается через gTR.exe или gTR.cmd. Этот локальный комплект Windows подготовлен без подписи издателя. [Обновление](UPGRADE.md)
